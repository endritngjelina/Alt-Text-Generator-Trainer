      Alt Text Best Practices

      1. Be Concise Yet Descriptive

      Aim for 125 characters or less. Screen readers may cut off longer descriptions.

      ✓ Good: "Woman smiling while working on laptop in modern office"

      ✗ Bad: "Photo of a woman"

      2. Convey Content and Function

      Describe what the image shows and why it's there.

      ✓ Good: "Bar chart showing 30% increase in quarterly sales"

      ✗ Bad: "Chart"

      3. Avoid Redundancy

      Don't start with "Image of..." or "Picture of..." - it's implied.

      ✓ Good: "Golden retriever playing fetch in park"

      ✗ Bad: "Image of a golden retriever playing fetch in a park"

      4. Context Matters

      Decorative images should have empty alt text (alt=""). Functional images need to describe the action.

      For a download button: "Download PDF report"

      5. Include Relevant Text

      If an image contains important text, include it in the alt text.

      ✓ Good: "Road sign reading 'Speed Limit 25'"

      6. Don't Describe Emotions You Can't Verify

      Focus on observable details rather than assumed emotions.

      ✓ Good: "Person smiling at camera"

      ✗ Bad: "Happy person" (smiling is observable; happiness is an assumption)

      Pro Tip

      Ask yourself: "If I couldn't see this image, what would I need to know?" Write alt text that answers that question clearly and concisely.
